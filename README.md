# Otomoto — подбор авто

Автоматический отчёт по поиску автомобиля: пара + собака, Познань.

**Критерии:** автомат · камера + парктроники · 2016+ · до 45 000 zł · бензин/гибрид, до 260 тыс. км.

Отчёт помечает объявления по уровню риска:
- 🟢 чисто
- 🟡 есть вопросы
- 🔴 отбраковано (повреждения, EPC, жор масла и т.п.)

Обновляется автоматически.

- `index.html` — отчёт (откройте ссылку Pages)
- `report.csv` — таблица для Excel
- `report.json` — сырые данные
